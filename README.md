# 理小办 · 校园办事卡生成器

依据《「理小办」作品说明文档》实现的**可运行演示应用**。零依赖静态站点，**双击 `index.html` 即可打开**，可离线运行，无后端、无外部接口。

## 它实现了文档里的什么

| 文档主张 | 应用中的落地位置 |
|---|---|
| 三智能体各管一段、互不越界 | 控制台右侧「三路接力过程」，四段依次点亮，每段头部写明**不做什么** |
| ① 信息智能体「查得准」 | 只输出带出处的原始事实表（事实 / 出处 / 位置 / 核实状态），不推断顺序、不给建议 |
| ② 规划智能体「排得顺」 | 输出分支判定、依赖识别、排序结果，以及**未进入你路径的步骤及原因** |
| ③ 执行助手「做得成」 | 只补齐入口 / 地点 / 材料 / 注意四字段，不修改事实、不调整顺序 |
| 理小办统一收口 → 办事卡 | 「结论先行 + 步骤可执行 + 依据可追溯」三张表 + 待核实清单 |
| 覆盖三校区差异 | 校区下拉切换，只影响**地点与办公时间**，不影响事实与步骤顺序 |
| 换三样东西换一个场景 | 已按同一结构实现 5 个场景，迁移三步说明见页面「场景库」 |
| 未测不填估算值 | 效果数据区四项全部显示「待实测」，保持空白 |

## 已配置场景

| 场景 | 候选步骤 | 依据条数 | 分支 |
|---|---|---|---|
| 校园卡丢失与补办（主线） | 7 | 7 | 密码是否改过、能否找回 |
| 学生证补办 | 6 | 5 | 是否加急 |
| 宿舍设施报修 | 5 | 4 | 是否紧急 |
| 晚归 / 夜不归宿请假 | 5 | 4 | 事前 or 事后 |
| 图书馆研讨间预约 | 5 | 5 | 人数是否达标 |

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 页面结构 |
| `assets/style.css` | 全部样式，含 `@media print` 打印样式 |
| `assets/data.js` | 场景数据：校区、事实（含出处与核实状态）、分支、步骤（含校区差异） |
| `assets/app.js` | 触发匹配、依赖与分支规划、三路渲染、办事卡生成、Markdown 导出 |
| `smoke-test.js` | 冒烟测试，`node smoke-test.js`，41 项断言 |
| `id-check.js` | 校验 HTML 元素 id 与 JS 引用一致性 |

## 用于比赛

- 可直接作为**操作录屏**素材（≤5 分钟）：输入问题 → 三路接力 → 办事卡 → 切分支 → 切校区；
- 办事卡支持**一键复制 Markdown** 或**打印 / 存 PDF**，可作为图文教程的截图素材；
- 打印样式已隐藏导航与非卡片区域，直接得到一张干净的办事卡。

## ⚠️ 必须替换的内容

`assets/data.js` 中：

- `v: 'doc'` 的条目 —— 来自《作品说明文档》的示例事实；
- `v: 'todo'` 的条目 —— **占位内容，全部标 `[待核实]`**，必须向学校相关部门核实后替换或删除；
- 所有**地点、办公时间、费用、电话**均为占位示例。

数据字段说明统一记录在 `data.js` 顶部注释中，替换时请勿删除该注释。

## 诚实边界

- 演示不收集、不上传任何用户输入；
- 办事卡底部固定附免责声明：「不代表学校办理结果」；
- 「使用前必须先确认」区块自动汇总所有 `[待核实]` 内容，**不会被自动补全**。
